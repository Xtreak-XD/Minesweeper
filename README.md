# 🧨 Minesweeper - Python Tkinter Edition

[![Run on Replit](https://replit.com/badge/github/Xtreak-XD/Minesweeper)](https://replit.com/@mikeandresavila/Minesweeper)

This is a fully functional **Minesweeper game** built in Python using the **Tkinter GUI library**. Players can choose their own custom grid size (up to 25×25), place flags, and reveal tiles — just like the classic version! The game features a timer, flag counter, and pop-up dialogs for winning or losing.

---

## 🎮 Features

- Customizable grid size (rows and columns)
- Randomly generated mine placements
- Right-click to place and remove flags (`?`)
- Automatically reveals adjacent cells when a blank tile is clicked
- Game timer to track your completion time
- Endgame pop-up with retry options
- Color-coded tiles based on nearby mine count

---

## 🛠 Technologies Used

- Python 3
- Tkinter (for GUI)
- `random` and `time` modules
